# MDB Production Board

Phase 1: interactive view/arrange layer for the wall Smart TV. No backend,
no data persistence beyond this browser's localStorage. Mirrors the
physical production board (see MDB Ops Deck, week 4/5, for the reference
layout): jobs x days grid, resource rows (dumpsters, camera/sign,
unavailable/maintenance, equipment, trailers, trucks), draggable colored
cards, custom color wheel, freehand pen/draw overlay.

Phase 2 (later): real create/edit/delete + persistence once the display is
physically up and working.
